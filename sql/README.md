# SQL Queries

This folder contains all SQL queries used to analyze the Financial Transactions Dataset.

The analysis focuses on transaction performance, customer behavior, merchant performance, payment methods, and transaction success rates.

## Analysis Topics

### 1. Monthly Transaction & Spending Trend

**Business Question**

How has transaction performance changed over time?

**Objective**

Analyze monthly transaction volume, total spending, and average transaction value to identify trends and seasonality.

**File**

`01_monthly_trend_analysis.sql`

---

### 2. Merchant Category Performance

**Business Question**

Which merchant categories generate the highest spending?

**Objective**

Analyze transaction volume, spending contribution, and average transaction value across merchant categories.

**File**

`02_merchant_category_analysis.sql`

---

### 3. Card Type Performance

**Business Question**

Which card types generate the highest transaction volume and spending?

**Objective**

Evaluate payment method performance by comparing transaction count, spending contribution, and average transaction value.

**File**

`03_card_type_performance.sql`

---

### 4. Top Customer Spending Analysis

**Business Question**

Who are the highest-value customers?

**Objective**

Identify customers with the highest total spending and rank them based on their contribution.

**File**

`04_top_customer_analysis.sql`

---

### 5. Income Group Analysis

**Business Question**

Do higher-income customers generate higher spending?

**Objective**

Analyze the relationship between customer income levels and spending behavior.

**File**

`05_income_group_analysis.sql`

---

### 6. Transaction Success Rate & Error Analysis

**Business Question**

How successful are transactions, and what are the most common causes of failed transactions?

**Objectives**

* Measure transaction success and failure rates.
* Identify the most common transaction error types.
* Understand the primary causes of transaction failures.

**Files**

`06_transaction_success_rate_analysis.sql`

---
